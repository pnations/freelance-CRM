# Security Policy

## Supported Versions

This project is maintained on a best-effort basis. Reported vulnerabilities will be assessed against the latest release.

## Reporting a Vulnerability

- Do not open public issues for sensitive security reports.
- Email the maintainer or open a private security advisory (GitHub Security Advisories if enabled).
- Include steps to reproduce, impact, and any suggested fixes.

We aim to acknowledge reports within 72 hours.
